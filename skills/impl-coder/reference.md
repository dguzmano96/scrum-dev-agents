# Impl Coder — tips modelos medianos

1. Leer 1–2 archivos vecinos del mismo módulo antes de escribir.
2. Copiar convenciones de nombres/exports.
3. No introducir carpeta nueva si ya existe lugar obvio.
4. Tras editar: releer AC del paso actual.
5. Si el compilador/linter falla por decisión de diseño → decision-gate, no “apañar” ampliando scope.
