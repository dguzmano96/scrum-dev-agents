# Quality rubric — HU

Cada dimensión: 1–3. Max 24. Nota = (total / 24) × 10.

| Dimensión | 1 | 2 | 3 |
|-----------|---|---|---|
| 1. Claridad de persona | "usuario" genérico | Rol claro | Rol + contexto/permisos |
| 2. Valor de negocio medible | "so that" vago | Beneficio claro | Beneficio + métrica/impacto |
| 3. Calidad de AC | Vagos / no medibles | Lista útil | Declarativos, medibles, sin Gherkin |
| 4. Cobertura BDD | <2 tipos | 2–3 tipos | Happy + validación + edge + fallo |
| 5. Tamaño | >1 sprint | Cabe en sprint | 1–3 días ideal |
| 6. Edge cases | Solo happy | 1 edge | Edge + error explícitos |
| 7. Dependencias | Implícitas | Parciales | Todas nombradas (HU/sistemas) |
| 8. Concisión + NFRs + OoS | Ruido / vaguedad | Aceptable | NFRs con umbral + out of scope |

**≥9.0** ready · **7.0–8.9** refine · **<7.0** rework/split
